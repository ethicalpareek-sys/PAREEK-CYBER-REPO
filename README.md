## 🚨 Pehle Yeh Padho — Important Legal Baat

Yeh repository **sirf** in kaamon ke liye hai: **padhai, ethical hacking, authorized penetration testing, CTF competitions, apni lab, defense seekhna, aur security research.**

**Yeh KABHI mat karo:**
- ❌ Kisi aur ke computer/website/account ko hack karna
- ❌ Bina likhit permission kisi bhi system pe attack
- ❌ Random IP addresses scan karna

**Yaad rakho:** Bina permission kisi ke system mein ghusna **crime hai**. India mein IT Act 2000 ke tahat **3 saal tak jail** aur fine ho sakta hai. USA mein CFAA, UK mein Computer Misuse Act — sab jagah illegal hai.

**Saare labs sirf yeh use karte hain:** `localhost`, DVWA, Juice Shop, TryHackMe, HTB, PortSwigger, apne VMs, authorized bug bounty.

## 🧠 Learning Philosophy

1. **Pehle basics** — Fundamentals skip mat karo
2. **Haath se karo** — Sirf padhna kaafi nahi, lab karo
3. **Defense aur Offense dono** — Dono taraf samjho
4. **Ethics pehle** — Authorization non-negotiable
5. **Document karo** — Jo explain nahi kar sakte, woh nahi jaante
6. **Portfolio banao** — Certificates se zyada projects kaam aate hain

**Progress track karne ke liye:**
```
[ ] Shuru nahi kiya
[ ] Padh raha hoon
[ ] Practice ki
[ ] Project banaya
[ ] Test kiya
[ ] Kisi ko explain kar sakta hoon
[ ] Problem solve kar sakta hoon
[ ] Expert
```
